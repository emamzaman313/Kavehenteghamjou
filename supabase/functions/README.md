# Supabase Edge Functions

## `access-code-login`

تابع ورود عمومی با کد دسترسی مشترک سایت:

- `status`: فقط وضعیت روشن/خاموش قابلیت را برمی‌گرداند.
- `login`: کد شش‌کاراکتری را در دیتابیس با bcrypt بررسی می‌کند؛ پس از پنج تلاش اشتباه، محدودیت ۱۵ دقیقه‌ای برای مبدأ درخواست اعمال می‌شود.
- `admin_get` و `admin_update`: فقط برای شناسه‌هایی که در `public.site_access_admins` ثبت شده‌اند؛ امکان تغییر وضعیت و تنظیم کد جدید را می‌دهد.
- پس از ورود موفق، برای هر نفر یک حساب مهمان مستقل Supabase ساخته می‌شود؛ مهمان به حساب مدیر یا سایر کاربران وارد نمی‌شود.
- کد خام در مرورگر، جدول پایگاه داده یا مخزن ذخیره نمی‌شود؛ فقط هش bcrypt در دیتابیس می‌ماند.
- تابع با `verify_jwt=false` منتشر شده است، چون مسیرهای عمومی هم دارد؛ مسیرهای مدیریتی در خود تابع Bearer token را با Auth اعتبارسنجی می‌کنند.
- در مرورگر یا Android هرگز `service_role`، کلید خصوصی یا گذرواژه مهمان قرار ندهید.

کد اولیه فقط در پروژه زنده Supabase مقداردهی شده است؛ مقدار متن خام آن عمداً داخل Git قرار نگرفته است. مدیر باید کد ساده اولیه را بعد از اولین ورود به کدی قوی‌تر تغییر دهد.

## کارهای دیگر باقی‌مانده

- تولید Signed URL برای دانلود فقط پس از بررسی عضویت/مجوز فایل
- تکمیل وضعیت فایل و cleanup فایل‌های orphaned بعد از آپلود
- FCM sender و fan-out اعلان
- moderation و rate limiting سراسری
- عملیات امتیازدهی/نشان‌ها و نقش‌های مدیریتی از سمت سرور
