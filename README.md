# کاوه انتقامجو

پروژه‌ای برای ساخت یک پیام‌رسان و شبکه اجتماعی با تجربه‌ای الهام‌گرفته از پیام‌رسان‌ها و شبکه‌های اجتماعی مدرن.

## وضعیت مخزن

این مخزن برای آغاز نگهداری سورس‌کد پروژه ایجاد شده است. مستندات فنی، ساختار پوشه‌ها و راهنمای اجرا در ادامه توسعه به این فایل افزوده می‌شوند.

## اصول امنیتی

- هیچ‌گاه کلیدهای خصوصی، رمزها، توکن‌ها یا فایل‌های حاوی اطلاعات محرمانه را در مخزن قرار ندهید.
- تنظیمات حساس باید از طریق متغیرهای محیطی و مدیریت امن اسرار انجام شوند.
- پیش از انتشار عمومی سورس، فایل‌ها و تاریخچه commitها را از نظر وجود اطلاعات محرمانه بررسی کنید.
