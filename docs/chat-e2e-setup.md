# راه‌اندازی آزمون واقعی دوحسابی چت

این آزمون با دو کاربر واقعی Supabase اجرا می‌شود و موارد زیر را بررسی می‌کند:

- ورود مستقل دو حساب با ایمیل و رمز عبور
- ساخت گفتگوی خصوصی با RPC فعلی
- عضویت و مشاهده گفتگو از حساب دوم
- ثبت پیام، دریافت رویداد Realtime و خواندن پیام از حساب دوم
- به‌روزرسانی و مشاهده read cursor
- آپلود فایل در Bucket خصوصی، ثبت metadata و اتصال به پیام
- دانلود همان فایل از حساب دوم و مقایسه بایت‌ها و SHA-256
- رد دسترسی anonymous به metadata و فایل خصوصی

## آماده‌سازی یک‌باره

1. در Supabase Auth دو حساب آزمایشی مستقل بسازید یا از دو حساب آزمایشی موجود استفاده کنید.
2. اگر تأیید ایمیل فعال است، هر دو حساب باید ایمیل تأییدشده داشته باشند.
3. این حساب‌ها را فقط برای آزمون نگه دارید؛ آزمون یک گفتگوی خصوصی، دو پیام و یک فایل آزمایشی در دیتابیس ایجاد می‌کند.
4. در GitHub → Settings → Secrets and variables → Actions → Secrets این چهار Secret را بسازید:

   - `KAVEH_E2E_USER_A_EMAIL`
   - `KAVEH_E2E_USER_A_PASSWORD`
   - `KAVEH_E2E_USER_B_EMAIL`
   - `KAVEH_E2E_USER_B_PASSWORD`

رمزها را در چت، فایل‌های مخزن یا Commitها قرار ندهید.

## اجرای آزمون

در GitHub → Actions → **Chat E2E** → **Run workflow** را اجرا کنید. نتیجه هر مرحله در Log نمایش داده می‌شود.

آزمون هیچ رکورد یا فایلی را حذف نمی‌کند؛ داده‌های آزمایشی برای بررسی بعدی باقی می‌مانند. به همین دلیل حتماً از دو حساب اختصاصی تست استفاده کنید، نه حساب‌های شخصی اصلی.

این آزمون مسیر ایمیل/رمز عبور و backend چت را پوشش می‌دهد؛ Google OAuth باید جداگانه با Provider واقعی و Google Client ID/Secret پیکربندی و روی دستگاه آزمایش شود.


## وضعیت اجرای آزمون در ۱۸ نوامبر ۲۰۲۶

- در ممیزی read-only پروژه Supabase، تعداد `auth.users` و `profiles` صفر بود؛ دو حساب اختصاصی برای تست در پروژه مشاهده نشد.
- Workflow `Chat E2E` در این مأموریت اجرا نشده است؛ وجود فایل Workflow یا موفقیت Build جایگزین نتیجهٔ دوحسابی نیست.
- چهار GitHub Secret این راهنما باید توسط مالک در تنظیمات امن Actions ایجاد شود. هیچ رمز عبوری در مخزن یا چت ثبت نشود.
- پس از ایجاد دو حساب تست و تنظیم Secrets، Workflow را اجرا و نتیجهٔ واقعی Realtime، read cursor، دسترسی Storage و SHA-256 را بررسی کنید.
